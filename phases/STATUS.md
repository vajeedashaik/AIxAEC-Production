### Deviations and things to know
- **context7 was not authenticated** in the P0 session; library APIs were checked against the installed packages' own docs and type definitions instead.
- **Installed versions are newer than the docs assume**: msw 3 (`onUnhandledFrame`), Clerk 7 / Core 3 (`<Show>`, no auto keyless, `createRouteMatcher` deprecated → proxy uses a path regex), Next 16 `cacheComponents` (runtime hooks under `<Suspense>`), vitest 5.
- **Mock-mode dev bypass**: with `NEXT_PUBLIC_API_MOCKING=on` in development, the Clerk route guard is skipped so P5/P6 can work offline. Never active in production.
- The API client test runs in vitest's `node` environment (jsdom's `File`/`FormData` break MSW's multipart parser); jsdom stays the default for component tests.
- `fastapi.testclient` prints a Starlette deprecation warning about `httpx`; harmless.
- Fixtures are generated by `fixtures/build_models.py` and `build_api_examples.py`; tests fail if the committed JSON drifts from them.
