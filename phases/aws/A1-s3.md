# A1: S3 for artifacts

**Switch:** `BLOB_BACKEND=hybrid` (default `supabase`). Needs `AWS_REGION`, `S3_BUCKET`.

**Goal:** vision artifacts live in S3. Source uploads stay in Supabase Storage.

**Files**
- New `services/api/app/aws/s3.py`: `S3BlobStore` implements `BlobStore` from `app/storage.py`. `RoutedBlobStore` sends named logical buckets to a chosen store and everything else to the default.
- Edit `app/config.py` and `app/container.py`.

**Requirements**
- One real bucket. The logical bucket name becomes a key prefix (`artifacts/<key>`).
- `signed_urls` returns presigned GET URLs valid for `SIGNED_URL_TTL_SECONDS`.
- `delete_prefix` pages through the keys, deletes in batches and treats per-key errors as a failure.
- Any `BotoCoreError` or `ClientError` becomes `ServiceError(502, UPSTREAM_UNAVAILABLE, "File storage is unavailable.")`.
- `jobs.py`, `repo.py` and `v1.py` stay unchanged.

**Tests (moto):** put/get round trip, presigned URL contains the key and an expiry, `delete_prefix` removes only that prefix across more than one page, routing sends `artifacts` to S3 and `floorplans` to the default, missing object maps to `ServiceError`, settings refuse `hybrid` without a bucket.
